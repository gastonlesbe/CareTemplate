# Documentación del Proyecto

Este directorio contiene toda la documentación del proyecto organizada por categorías.

## 📁 Estructura de Carpetas

### `/docs/fixes/`
Documentación sobre correcciones de bugs y problemas específicos:
- `FIX_APP_ADS_404.md` - Corrección del error 404 en app-ads.txt
- `FIX_CARPAL_SYNC_ERROR.md` - Corrección de errores de sincronización en CarPal
- `FIX_FIRESTORE_FAILED_PRECONDITION.md` - Corrección de errores de Firestore
- `FIX_SECURITY_EXCEPTION.md` - Corrección de excepciones de seguridad

### `/docs/guides/`
Guías y tutoriales:
- `APP_ADS_TXT_*.md` - Guías sobre app-ads.txt
- `COMO_VER_CODIGO_RECUPERACION_FIREBASE.md` - Cómo ver códigos de recuperación
- `ENCONTRAR_SITIO_WEB_PLAY_CONSOLE.md` - Cómo encontrar el sitio web en Play Console
- `PASOS_APP_ADS_TXT.md` - Pasos para configurar app-ads.txt
- `VERIFICAR_ADMOB.md` - Cómo verificar AdMob

### `/docs/play-store/`
Contenido para Google Play Store:
- `APP_DESCRIPTION*.md` - Descripciones de la app
- `FEATURE_GRAPHIC_GUIDE.md` - Guía para crear feature graphics
- `GOOGLE_SITES_GUIDE.md` - Guía para Google Sites
- `ICON_GUIDE.md` - Guía para crear iconos
- `PLAY_STORE_CONTENT.md` - Contenido general de Play Store
- `STORE_TAGS.md` - Tags para la tienda

### `/docs/release/`
Notas de versión y documentación de releases:
- `VERSION_NOTES_1.1.md` - Notas de versión 1.1
- `VERSION_NOTES_1.2.md` - Notas de versión 1.2
- `VERSION_NOTES_1.2_SHORT.md` - Notas cortas de versión 1.2
- `VERSION_NOTES_1.4.md` - Notas de versión 1.4
- `VERSION_NOTES_1.4_PLAY_CONSOLE.txt` - Notas formateadas para Play Console
- `BUILD_RELEASE.md` - Guía para construir releases
- `RELEASE_CHECKLIST.md` - Checklist de release
- `RELEASE_READY.md` - Documentación de releases listos
- `CARPAL_*.md` - Documentación específica de CarPal

### `/docs/setup/`
Configuración y setup del proyecto:
- `FIRESTORE_RULES_*.txt` - Reglas de Firestore (completas, recovery, seguras)
- `CARPAL_SETUP.md` - Setup de CarPal
- `FIRESTORE_RULES_*.md` - Documentación de reglas de Firestore
- `KEYSTORE_INFO.md` - Información sobre el keystore
- `USER_ID_SUBSCRIPTIONS.md` - Sistema de IDs de usuario y suscripciones
- `USER_RECOVERY_SYSTEM.md` - Sistema de recuperación de usuarios

### `/docs/` (raíz)
Documentación general:
- `README.md` - Este archivo
- `PRIVACY_POLICY.md` - Política de privacidad (markdown)
- `PRIVACY_POLICY.html` - Política de privacidad (HTML)
- `PRIVACY_POLICY_GOOGLE_SITES.md` - Política de privacidad para Google Sites
- `PRIVACY_POLICY_OPTIONS.md` - Opciones de política de privacidad
- `NO_ACTUALIZAR_APP.md` - Notas sobre actualizaciones
- `IMPLEMENTACION_SEGURIDAD.md` - Implementación de seguridad
- `SECURITY_IMPROVEMENT.md` - Mejoras de seguridad
- `RESUMEN_APP_ADS.txt` - Resumen sobre app-ads.txt
- `VERIFICACION_APP_ADS.txt` - Verificación de app-ads.txt

## 📝 Archivos en la Raíz del Proyecto

Algunos archivos deben permanecer en la raíz del proyecto:
- `app-ads.txt` - Requerido por Google Play en la raíz
- `keystore.properties.example` - Ejemplo de configuración de keystore

## 🔍 Búsqueda Rápida

- **Notas de versión**: Busca en `/docs/release/`
- **Configuración de Firestore**: Busca en `/docs/setup/`
- **Guías de Play Store**: Busca en `/docs/play-store/`
- **Correcciones de bugs**: Busca en `/docs/fixes/`
- **Política de privacidad**: Busca en `/docs/PRIVACY_POLICY*`
