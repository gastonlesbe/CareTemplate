# Política de Privacidad - HousePal

**Última actualización:** 17 de diciembre de 2024

## Introducción

HousePal ("nosotros", "nuestro" o "la aplicación") se compromete a proteger tu privacidad. Esta Política de Privacidad explica cómo recopilamos, usamos y protegemos tu información cuando usas nuestra aplicación móvil HousePal.

## Información que Recopilamos

### Información que Tú Proporcionas
- **Datos de tus propiedades/hogares**: Nombres, direcciones, notas y otra información que ingresas sobre tus propiedades
- **Eventos y recordatorios**: Información sobre eventos, mantenimientos, reparaciones, pagos de servicios y recordatorios que creas
- **Gastos**: Información sobre gastos relacionados con tus propiedades (servicios, mantenimiento, reparaciones, mejoras, etc.)

### Información Recopilada Automáticamente
- **Datos de uso**: Información sobre cómo usas la aplicación
- **Identificadores de dispositivo**: Para sincronizar tus datos entre dispositivos
- **Advertising ID (ID de publicidad)**: Recopilado por Appodeal SDK para mostrar anuncios relevantes
- **Datos de Firebase Analytics**: Para mejorar la aplicación (anónimos y agregados)

## Cómo Usamos tu Información

Utilizamos la información recopilada para:
- Proporcionar y mejorar nuestros servicios
- Sincronizar tus datos entre dispositivos usando Firebase
- Analizar el uso de la aplicación para mejoras (datos anónimos)
- Mostrar anuncios relevantes a través de Appodeal

## Servicios de Terceros

### Google Firebase
- **Propósito**: Almacenamiento y sincronización de datos
- **Datos**: Tus eventos, propiedades y gastos se almacenan en Firebase Firestore
- **Autenticación**: Usamos autenticación anónima de Firebase
- **Política**: [Política de Privacidad de Firebase](https://firebase.google.com/support/privacy)

### Appodeal
- **Propósito**: Mostrar anuncios en la aplicación
- **Datos**: Recopila el **Advertising ID** (ID de publicidad de Google) para mostrar anuncios personalizados y relevantes. Este ID se comparte con redes publicitarias asociadas a Appodeal (incluyendo Google AdMob) únicamente para fines publicitarios.
- **Política**: [Política de Privacidad de Appodeal](https://appodeal.com/privacy-policy)

### Firebase Analytics
- **Propósito**: Analizar el uso de la aplicación
- **Datos**: Recopila IDs de dispositivo de forma anónima para analizar el uso de la aplicación, identificar problemas y mejorar nuestros servicios. Estos datos son agregados y no identifican personalmente a los usuarios.
- **Política**: [Política de Privacidad de Google Analytics](https://policies.google.com/privacy)

## Almacenamiento de Datos

Tus datos se almacenan de forma segura en:
- **Dispositivo local**: Usando Room Database (base de datos local)
- **Nube**: Firebase Firestore (servidores de Google)

## Seguridad

Implementamos medidas de seguridad para proteger tu información:
- Encriptación de datos en tránsito (HTTPS)
- Autenticación segura a través de Firebase
- Acceso restringido a tus datos (solo tú puedes acceder)

## Tus Derechos

Tienes derecho a:
- Acceder a tus datos personales
- Solicitar la eliminación de tus datos
- Exportar tus datos
- Retirar tu consentimiento
- Optar por no recibir publicidad personalizada (a través de la configuración de tu dispositivo)

Para ejercer estos derechos, contáctanos a través de la información de contacto proporcionada.

## Retención de Datos

Conservamos tus datos mientras uses la aplicación. Puedes eliminar tus datos en cualquier momento desde la aplicación o contactándonos.

## Cambios a esta Política

Podemos actualizar esta Política de Privacidad ocasionalmente. Te notificaremos de cualquier cambio publicando la nueva política en esta página y actualizando la fecha de "Última actualización".
