# Notas de Versión 2.1 - CarePal: Houses

<es-ES>
✨ Nuevas características y mejoras:

📚 Tutorial interactivo mejorado con mejor navegación entre pasos
🌍 Soporte completo para español e inglés según el idioma de tu dispositivo
🎉 Mensajes de bienvenida al crear tu primera casa y evento
✏️ Mejoras en edición: al editar un evento con repetición, se actualizan todas las repeticiones automáticamente
🔔 Notificaciones y alertas personalizables para eventos importantes
💰 Seguimiento de gastos y costos por casa
